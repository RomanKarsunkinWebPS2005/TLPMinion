# 03. Семантика языка
## 1. Структура программы

Программа состоит из элементов верхнего уровня, которыми могут быть:
- Объявления констант, переменных или функций.
- Инструкции (вызовы функций, присваивания).

## 2. Типы данных

Язык поддерживает пять встроенных типов данных:

| Тип | Описание | Размер | Диапазон / Значения | Поддерживаемые арифметические операции
|-----|----------|--------|---------------------|--------|
| `Int` | Целое число со знаком | 32 бита | −2³¹ … 2³¹−1 (−2147483648 … 2147483647) | `+`, `-`, `*`, `/`, `%` |
| `Float` | Число с плавающей точкой | 64 бита | от 5,0 * 10^-324 до 1,7 * 10^308 | `+`, `-`, `*`, `/`, `**` |
| `Bool` | Логический тип | 8 бит | `true`, `false` | `!`, `&&`, `\|\|`|
| `String` | Строка произвольной длины | переменный | UTF-16 кодировка | `+` ( конкатенация строк)
| `Void` | Отсутствие значения | — | Используется только как тип возврата функции |

Неявные преобразования типов не поддерживаются.

## 3. Переменные и константы
Переменные объявляются с помощью ключевых слов var (изменяемая) или let (неизменяемая).
- `var`: значение может быть изменено оператором присваивания. Инициализация не обязательна.
- `let`: значение присваивается один раз при объявлении и не может быть изменено.

Инициализация константы (const) обязательна и должна происходить в момент объявления. Выражение инициализации должно вычисляться на этапе компиляции.

## 4. Область видимости

| Область видимости | Описание | Доступные сущности |
|---------|----------|-------------------|
| Глобальная | Весь файл программы | `const`, `func`, `var`, `let` на верхнем уровне |
| Функции | Тело функции | Параметры, локальные переменные |
| Блок | Внутри `{ }` | Переменные, объявленные в блоке |

- Идентификатор переменной должен быть уникальным в пределах текущей области видимости
- Использование идентификатора до его объявления невозможно
- Переменная, объявленная внутри блока, доступна в этом блоке и во блоках, которые вложены в текущий блок
- При объявлении переменной внутри блока с таким же идентификатором, как и во внешней области, внешняя становится недоступна до выхода из блока
Внутри блока можно объявить переменную с тем же именем, что и во внешней области. Внутри блока будет видна новая переменная, внешняя становится недоступной до выхода из блока

### Время жизни

| Сущность | Время создания | Время уничтожения |
|----------|---------------|-------------------|
| Глобальная переменная | До начала выполнения программы | После завершения программы |
| Локальная переменная | При входе в блок | При выходе из блока |
| Параметр функции | При вызове функции | При завершении функции |
| Константа | На этапе компиляции | - |

## 5. Выражения

###  Порядок вычисления
- Выражения вычисляются в соответсвии с порядком приоритета операций
- Операнды бинарных операторов вычисляются слева направо
- Операторы `&&`, `||`, `?:` поддерживают short-circuit evaluation:

    | Оператор | Правило |
    |----------|---------|
    | `a && b` | Если `a == false`, `b` не вычисляется |
    | `a \|\| b` | Если `a == true`, `b` не вычисляется |
    | `a ? b : c` | Вычисляется только `b` или только `c` в зависимости от `a` |


##### Операторы сравнения
| Оператор | Операнды | Результат |
|----------|---------|-----------|
| `==`, `!=` | Любые совместимые типы | `Bool` |
| `<`, `<=`, `>`, `>=` | `Int`, `Float`, `String` | `Bool` |

##### Логические операторы

| Оператор | Операнд | Результат |
|----------|---------|-----------|
| `!` | `Bool` | `Bool` |
| `&&`, `\|\|` | `Bool`, `Bool` | `Bool` |


## 6. Встроенные функции

| Функция | Сигнатура | Описание |
|---------|-----------|----------|
| abs | Float abs(Float x) | Модуль числа |
| min | Float min(Float a, Float b) | Минимум из аргументов |
| max | Float max(Float a, Float b) | Максимум из аргументов |



## 6. Ввод и вывод

### 6.1. Вывод (`print`)

- Выражение вычисляется
- Результат преобразуется в строку
- Строка выводится в стандартный поток вывода
- Перевод строки не добавляется автоматически

### 6.2. Ввод (`input`)

- Тип вводимого значения должен соответствовать типу переменной
- При некорректном вводе возникает ошибка выполнения
- Читается одно слово с клавиатуры (последовательность символов без пробелов, табуляций, перевода строки)
- Чтение прекращается при встрече первого пробельного символа
- Ведущие и завершающие пробелы игнорируются
