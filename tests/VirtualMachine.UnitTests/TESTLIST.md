# Список тестов модуля VirtualMachine

Встроенные функции

- [x] Функция print (вывод через `IEnvironment.Print`)
- [x] Функция input для типа Int (`InputInt`)
- [x] Функция input для типа Float (`InputFloat`)
- [x] Функция input для типа String (`InputString`)
- [x] Функция length (`StringLength`) — длина строки в кодовых единицах UTF-16
- [x] Функция substring (`StringSubstring`) — подстрока по `start` и `count`
- [x] substring вне диапазона — ошибка выполнения
- [x] Некорректный ввод при input (ожидаемая ошибка выполнения)
- [x] Пустой ввод / конец потока при чтении слова (согласованное исключение)

Остановка вычислений

- [x] Остановка виртуальной машины с нулевым кодом выхода (`Halt`)
- [x] Остановка виртуальной машины с ненулевым кодом выхода (`Halt`)

Стековые вычисления выражений

- [x] Операция сложения (`Add`) для Int, для Float и конкатенация двух строк
- [x] Операция вычитания (`Subtract`) для Int и для Float
- [x] Операция умножения (`Multiply`) для Int и для Float
- [x] Операция деления (`Divide`) для Int и для Float
- [x] Операция возведения в степень (`Power`) для Float
- [x] Операция деления по модулю (`Modulo`) для Int
- [x] Операция арифметического отрицания (`Negate`) для Int и для Float
- [x] Сложение и умножение в одном выражении (порядок на стеке)
- [x] Несколько арифметических операций в одном выражении
- [x] Добавление значения на стек (`Push`)
- [x] Удаление значения с вершины стека (`Pop`)
- [x] Деление на ноль для `Int` (исключение); для `Float` поведение CLR не проверяется. (Уточнить у аналитика по поведению при делении на ноль, так как сейчас нет контракта)

Объявление переменных и присваивание

- [x] Объявление для типа Int (`DefineVar`)
- [x] Объявление для типа Float (`DefineVar`)
- [x] Загрузка значения (`LoadVar`)
- [x] Присваивание в существующую переменную (`StoreVar`)
- [x] Повторное объявление того же имени в одной области (ошибка)
- [x] Присваивание в несуществующее имя (ошибка)

Области видимости

- [x] Вход в область (`PushVars`) и выход (`PopVars`)
- [x] Затенение имени (shadowing): `LoadVar` / `StoreVar` во вложенном блоке
- [x] Присваивание во внешнюю переменную, если во внутренней области имя не объявлено
- [x] После выхода из области внутренние имена недоступны

Сравнения, логика и переходы

- [x] `Equal`, `NotEqual`, `<`, `<=` для `Int`, `Float`, `String`, `Bool`; `>` / `>=` через свап операндов + `Less` / `LessOrEqual`
- [x] `Not`, `And`, `Or` для `Bool`
- [x] `Jump`, `JumpIfTrue`, `JumpIfFalse`
