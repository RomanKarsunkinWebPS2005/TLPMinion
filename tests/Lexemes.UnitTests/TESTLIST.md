# Список тестов Lexemes

## Идентификаторы и ключевые слова
- [x] Разбор идентификаторов: `alice`, `Bob`, `C00L`, `D_2`, `_tmp`, `x`.
- [x] Регистр имеет значение: `count`, `Count`, `COUNT` -> разные `Identifier`.
- [x] Разбор ключевых слов: `const`, `let`, `var`, `print`, `input`, `length`, `substring`.
- [x] Разбор типовых ключевых слов: `Int`, `Float`, `String`, `Void`, `Bool`.
- [x] Логические ключевые слова: `true`, `false`, `if`, `else`.
- [x] Похожие на ключевые слова идентификаторы не путаются с keyword: `printf`, `inputValue`, `Float32`, `lengthOf`, `substringx`, `trueish`, `falsey`.

## Cравнения и логика

- [x] `==`, `!=`, `<`, `<=`, `>`, `>=`
- [x] `&&`, `||`, `!`
- [x] `?` и `:` в выражении.
- [x] `**` и `==` в одной строке (`2**3==0`).

## Строковые литералы
- [x] Пустая строка `""`.
- [x] Обычное содержимое в кавычках.
- [x] Экранирование `\"`, `\\`, `\n`.
- [x] Незакрытая строка → `Error`.
- [x] Неизвестный escape → `Error`.

## Числовые литералы
- [x] Разбор целых (`IntLiteral`): `0`, `42`, `56789`.
- [x] Разбор вещественных (`FloatLiteral`): `3.14`, `0.0`, `10.25`.
- [x] Отрицательные  лексируются как оператор + литерал: `-7` -> `Minus`, `IntLiteral(7)`;
- [x] Недопустимый формат с точкой без дробной части: `12.` -> `IntLiteral(12)` и затем `Error` на `.`.
- [x] Недопустимый формат с точкой без целой части: `.5` -> `Error` на `.` и затем `IntLiteral(5)`.
- [x] Переполнение `Int`: число больше диапазона `int` возвращает `Error`.

## Операторы, разделители и скобки
- [x] Арифметические операторы: `+`, `-`, `*`, `/`, `%`.
- [x] Оператор степени: `**` -> `Power`.
- [x] Одинарная `*` не превращается в `Power`.
- [x] Разделители: `;`, `,`, `:`.
- [x] Скобки: `(`, `)`, `{`, `}`.
- [x] Присваивание: `=` -> `Assign`.

## Пробелы и комментарии
- [x] Пропуск пробельных символов: `' '`
- [x] Однострочные комментарии: `// ...` до конца строки.
- [x] Многострочные комментарии: `/* ... */`.
- [x] Ошибка на незакрытый многострочный комментарий: `/* ...` -> `Error`.

## Ошибочные лексемы
- [x] Неизвестный символ возвращает `Error` (например, `@`).
- [x] Лексер продолжает разбор после ошибки на предыдущем символе.
